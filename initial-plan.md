2048 Machine Learning System

This system is a system that using Evintkoo/automl to build and run machine learning that trained to achieved the highest score in 2048 game

Goal:
1. create a machine learning that is able to achieve the highest score using just automl module
2. testing and benchmarking the capability of automl to know the actual quality, capability, and result of the automl engine system
3. finding what machine learning algorithm that is the best used for this game problem

Steps:
1. create game environment: either clone another repo, or make our own 2048 game with all game rules etc
2. define the action that can be taken to play the game as the prediction output of the machine learning
3. define the current state as the state of the board and score
4. train the machine learning model using automl engine based on the input, state, output
5. collect all the data
6. create research report using IMRD standard


Out of scope
1. using automl via frontend to run the training
